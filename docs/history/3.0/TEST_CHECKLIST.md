# TEST_CHECKLIST — اختبار الهاتف قبل اعتماد النسخة

جميع البنود التالية **غير منفذة على هاتف** في بيئة التسليم. يُفضّل استخدام نسخة من بيانات فعلية مع نسخة احتياطية قبل التحقق، وتثبيت APK موقّع بالشهادة الأصلية فوق التطبيق دون إزالة التطبيق أو مسح بياناته.

## التوافق والبيانات

- [ ] أعداد التقاويم والشيفتات والمهام والمدفوعات والأرصدة قبل التحديث وبعده متساوية.
- [ ] Classic يحتفظ بالألوان والتخطيط والتقويم والأزرار والسلوك السابق.
- [ ] الانتقال بين Classic وPremium لا يغيّر البيانات أو اختيارات Classic.
- [ ] النسخ الاحتياطي والاستعادة يعملان كما في الأصل؛ تحقق من أن تخصيص Neo المحلي يحتاج ضبطًا مستقلًا بعد نقل الهاتف.
- [ ] Widgets والفتح من إشعار أو Widget ومحرر المهمة الصحيح تعمل.

## Appearance Studio

- [ ] الثيمات العشرة تعمل، وArctic White يبدأ بمعاينة Light.
- [ ] Dark / Light / Follow System / AMOLED تعمل؛ افحص الأسود الكامل للخلفية في AMOLED.
- [ ] إدخال Accent صحيح، واستبعاد HEX غير الصحيح، والعودة للون الثيم.
- [ ] التبديل بين كثافة اللون، وشكل البطاقة، واستدارة الزوايا، وGlass، وGlow يعطي أثرًا واضحًا.
- [ ] Rounded / Outlined يغيران الأيقونات المدعومة في الشاشات والمحررات.
- [ ] الخطوط الإنجليزية Sans / Condensed / Editorial تعطي اختلافًا حقيقيًا، والعربية متصلة.
- [ ] معاينة خيار ثم Discard لا تغيّر المظهر المحفوظ.
- [ ] Apply & save يحفظ كل الخيارات بعد إغلاق التطبيق بالقوة وإعادة فتحه.
- [ ] معاينة Defaults ثم Apply تعيد المظهر الافتراضي.
- [ ] مستويات الحركة الثلاثة تعمل، وReduce Motion يوقف حركات Neo المخصصة.

## الرئيسية والشيفتات

- [ ] الترحيب والتاريخ والشيفت الحالي والقادم والمهام من البيانات الفعلية، دون قيم تجريبية.
- [ ] إخفاء البطاقات وإعادة ترتيبها بأعلى/أسفل، ثم restart، يحافظ على الترتيب والاختيارات.
- [ ] إخفاء كل البطاقات وإغلاق لوحة اليوم لا يمنع الوصول للتقويم.
- [ ] Add shift / Add task / Today تعمل، ولا تعيد فتح إضافة قديمة عند الرجوع بين التبويبات.
- [ ] الشيفت الليلي 20:00–08:00 يظهر في يوم البداية وحده؛ حالته الحالية صحيحة أثناء امتداده لليوم التالي.
- [ ] شيفت 24 ساعة يظهر مرة واحدة ومدة 24 ساعة؛ حدود البداية والنهاية صحيحة.
- [ ] عدة شيفتات في اليوم تعرض ألوانًا ومؤشر الزيادة؛ لا يُفقد أي شيفت.
- [ ] Timeline: فلاتر المكان والتاريخ والحالة، ورسالة النطاق غير الصحيح، وShow more.
- [ ] مؤشر التعارض يوافق قواعد المحرك الأصلي؛ افتح التفاصيل وعدّل الوقت.
- [ ] الجداول والتقاويم: إنشاء/تعديل/حذف/إظهار/إخفاء/ترتيب/لون/تقويم نشط تعمل كما في الأصل.

## التقويم والمهام

- [ ] Month / Week / Day والتنقل بالأزرار والسحب وToday تعمل في العربية والإنجليزية.
- [ ] خلايا الشهر تتضمن الأيام الصحيحة، بما فيها شهر 28 يومًا وشهر يحتاج ستة صفوف.
- [ ] الرسم الجماعي يعمل بعد التنقل بين الشهور، ولا يحدد يومًا تلقائيًا بمجرد التنقل.
- [ ] حل التعارضات واستكمال قائمة الأيام والحفظ والإلغاء تعمل كما في الأصل.
- [ ] Quick Add يفتح تفاصيل اليوم أو لوحة الرسم، وإضافة مكان من اللوحة تصل إلى إدارته.
- [ ] مؤشرات المهام والعناصر تتبع اليوم والتقاويم الظاهرة، والتفاصيل والمحرر يعملان.
- [ ] بحث المهام بالعربية والإنجليزية، وأولوية المهمة، وتصنيف التقويم، وفلاتر اليوم/القادمة/المتأخرة/المكتملة/الكل.
- [ ] إنشاء وتعديل وإكمال وإلغاء إكمال وحذف مهمة؛ التكرار والتذكير والربط بالشيفت ومكان العمل لا تتعطل.

## المالية والأمان

- [ ] باستخدام نفس البيانات: المستحق والمستلم والمتبقي والتسويات والالتزامات متساوية بين Classic وPremium.
- [ ] الأشهر المغلقة وقيود التعديل والتحقق قبل الإجراءات المالية لم تتغير.
- [ ] PIN / Pattern / Biometric / Device credential تعمل حسب الإعدادات السابقة.
- [ ] قفل الحسابات ثم فتح المالية: لا مبلغ أو رسم قبل التحقق.
- [ ] والقفل فعال، افتح يومًا يحتوي التزامًا من التقويم ومن Timeline: القيم مخفية.
- [ ] بعد التحقق، جرّب عين إخفاء المبالغ: تختفي القيم ومؤشر التحصيل، بما في ذلك مبالغ تفاصيل اليوم.
- [ ] اترك التطبيق في الخلفية حتى انتهاء مهلة القفل، ثم عُد: لا ظهور عابر للقيم أثناء الانتقال.
- [ ] تسجيل وتعديل وحذف دفعة وتوزيعها، وإدارة مصادر الدخل وطرق الدفع والالتزامات، تعمل كما قبل التطوير.

## اللغة وإمكانية الوصول والأداء

- [ ] Arabic / English / System محفوظة بعد restart؛ RTL/LTR والسهام واتجاه الأرقام والمبالغ والتواريخ صحيحة.
- [ ] لا يتغير اسم أو ملاحظة أدخلها المستخدم عند تغيير اللغة.
- [ ] هاتف بعرض 320–360dp، وهاتف كبير، ووضع أفقي، وجهاز لوحي.
- [ ] حجم خط النظام 100% و150% و200% مع حجم التطبيق الافتراضي والأقصى: لا قص للأزرار والنصوص الأساسية، والتمرير متاح.
- [ ] TalkBack يقرأ تاريخ اليوم وعدد شيفتاته ومؤشراته، وأزرار التنقل والاختيار والمفاتيح بوضوح.
- [ ] التباين في Dark وLight مع Accent فاتح جدًا أو داكن جدًا؛ لا تظهر كبسولات بيضاء في تقويم Premium.
- [ ] مناطق لمس مريحة، وعدم تداخل الشريط السفلي مع Gesture Navigation أو أزرار النظام.
- [ ] فتح المالية أو المهام والتقويم مع بيانات كثيرة، والتمرير وتبديل الأشهر دون تجمد أو ضغط ملحوظ على البطارية.
