# طرز لاحقة | خارج نطاق التنفيذ الحالي

بعد قبول Premium يمكن إدراج Modern وLuxury وClassic كقيم styleId مستقرة. يبقى Classic الحالي مسار توافق لا يُستبدل تلقائيًا. يحدد الطراز typography/spacing/shape/surface/motion/illustration tokens فقط. يحدد Light/Dark/AMOLED/System الإضاءة مستقلة عن الطراز. تحسم الدالة المشتركة القيم بالترتيب: قيم الطراز، ثم الإضاءة الفعالة، ثم تخصيص المستخدم، ثم قيود التباين وتقليل الحركة. تبقى ألوان أماكن العمل وإعدادات النوع مستقلة، وتتعامل معها طبقة الإظهار بالتباين والرموز.

تستهلك الشاشات والمعاينات renderer واحدًا لكل مكون وتتعامل مع نماذج عرض واحدة. لا تصل الطرز للمخزن أو التحليل المالي أو محركات التعارض. لا تُنشأ شاشات أو routes بديلة لطراز جديد. تبقى المفاتيح الحالية والملفات المحفوظة قابلة للقراءة؛ أي styleId مستقبلي غير معروف يحتفظ بقيمته الخام ويستخدم Premium للعرض.

بوابة مستقبلية قبل الإدراج: parity لكل المتطلبات المحمية، لقطة تطبيق فعلية ومقارنة إنتاج/معاينة، RTL/LTR والخط المكبر، إضاءة النظام وتغيرها، إعادة تشغيل وترقية من تفضيلات محفوظة، حماية ألوان الورديات والخصوصية. لا تضف عناصر اختيار لطراز غير متاح.

أفكار مستقلة بعد القبول وبموافقة صريحة: جولة إعداد اختيارية من ثلاث خطوات، أو تصدير قراءة فقط لمخرجات الجدول. تستمر استثناءات النطاق المعتمد، ومنها Today dashboard جديد وخط زمني وتوقعات الدخل.
