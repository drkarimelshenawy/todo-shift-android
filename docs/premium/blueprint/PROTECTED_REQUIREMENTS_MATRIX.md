# سجل المتطلبات المحمية

130 بندًا من النطاق الأصلي، و12 تصحيح UX، وخمسة قيود قبول حالية غير مغطاة بالكامل بالصيغ السابقة. UX.03 يحتفظ بالدخول المباشر، والطلب الحالي يحكم عنصر التشغيل. البنود المنفية في الاعتماد تبقى حدودًا. المواضع أدناه نقاط دخول حالية أو مكونات مرشحة وفق تتبع المستودع؛ وجود ملف لا يثبت الوصول أو نجاح السلوك. عمود الفجوة يربط بسجل العيوب على مستوى المسار وقد لا ينطبق على كل فرع من الميزة. **كل حالات القبول معلقة للمرشح الجديد.** القرار وشرط التحقق في نفس الخانة. IDs القبول تشير إلى [QA](QA_ACCEPTANCE_MATRIX.md)، وIDs العيوب إلى [السجل](MASTER_DEFECT_REGISTER.md).
