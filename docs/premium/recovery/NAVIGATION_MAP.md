# Current navigation map

Tap counts below are source-derived from the main tab, not stopwatch/device usability acceptance. Exact catalog/Arabic labels: `NeoFeatureCatalog` in `NeoRescueComponents.kt`; static editor inventory and the 147-row traceability retain detailed workflow locations. Main order: Calendar / Schedules / Tasks / Finance / Settings (mirrored by the independent direction preference).

| Function | Primary location and control | Taps / behavior |
|---|---|---|

| Copy shifts / suggestions | Calendar header ⋮ → Copy / Favorites and next shift | 2 opens focused workflow, explicit review/confirmation. |

| Task quick add / search / filters | Tasks floating + / search / filters | 1 for compact title/date/save with advanced fields. Existing task actions retain edit/attachment/undo. |

The shell owns one feature title/guarded Back; child components retain their own headers only when hosted standalone/Classic. Settings local groups retain their own group heading under the Settings shell. Back returns to the actual saved origin; incoming intents pass the same leave gate. Finance display has one Privacy & Data page and a contextual Finance shortcut to it; state is not duplicated.
