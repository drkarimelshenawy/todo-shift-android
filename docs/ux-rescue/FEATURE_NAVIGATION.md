# Feature navigation map

Five tabs: Calendar / التقويم, Schedules / جداولي, Tasks / المهام, Finances / الحسابات, Settings / الإعدادات. Stable internal tab IDs preserve deep links. Counts exclude data entry/confirmation.

Calendar: header brush (1 tap) enters painting immediately; workplace (1) opens type strip; type (1) closes strip; day paints; eraser/Done stay fixed. Header calendar icon opens visibility/default manager (1). Day opens details (1), notes/edit/attachments are contextual. View selector, month arrows and Today are on calendar. Header search (1) finds categorized records and Settings routes.

Schedules: Shifts/Summary/Calendars are visible sections (1). Tasks: plus opens title/date/save (1), Advanced expands optional fields; task overflow opens edit/attachment/delete. Finances: Summary/Receipts/Obligations are visible (1); summary offers rates/statements/month review. Contextual header menu → focused operation is 2 taps.

Settings: Appearance group directly opens Studio (1), section expands (1 more). Other group → option is 2 taps. Search opens the same authoritative option.
