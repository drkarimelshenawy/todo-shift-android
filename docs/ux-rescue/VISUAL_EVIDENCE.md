# Rendered evidence and acceptance limits

26 actual MainActivity native Robolectric SDK28 window captures, using synthetic isolated fixture records. Two optional probe tests passed. No emulator or attached phone was available. The harness synchronizes frames; modal capture uses the distinct dialog window. Earlier failed/lagged captures are not delivery evidence.

Inspected English calendar, single/multiple/OFF fixtures, colored workplace/type painting, Schedules, Tasks, Finance, six Settings groups, vertical Studio and selected options; inspected Arabic AMOLED and narrow English large-text renders. These exposed and led to fixes for inherited black Dark/AMOLED foreground, duplicate OFF/priority labels, note marker crowding and narrow view-selector clipping.

Remaining: narrow header title is ellipsized; long mixed-language cell text truncates by design. Native render diagnostics do not establish real keyboard/IME insets, touch feel, TalkBack, hardware biometrics, launcher lifecycle, animation timing, all independent direction combinations, sustained memory/performance, or installed-app upgrade. User visual approval is still pending.
