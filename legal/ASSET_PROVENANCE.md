# Background asset provenance

The six `app/src/main/res/drawable/neo4_*.xml` landscape backgrounds are original vector illustrations authored in source for this upgrade. They use geometric paths and gradients, not stock photography or third-party image downloads. No attribution or external image license is being claimed for an unknown asset. Existing application icons remain from the supplied project.

Personal photographs are supplied explicitly through Android Photo Picker, resized into private app storage, and included in a local snapshot only when referenced by the current appearance or a saved profile. The user remains responsible for rights in their own photographs. Source ZIPs contain no user photographs.
